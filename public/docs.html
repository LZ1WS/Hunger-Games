2. The two languages

Mini-language mini

A safe, line-based language — one statement per line, no brackets. Ideal for most content. Covers logging, conditionals, item grants and alliance actions.

JavaScript js

Full JavaScript running in a sandboxed with(ctx) scope with helper functions. For advanced authors. Errors are caught and never crash the game.

4. Mini-language

One statement per line. Blank lines and lines starting with # or // are ignored.

Statements

StatementExampleEffect
set <name> to <value>set target to randomStore a value in memory (true/false, random, randomOther, or another ref).
log "…"log "{self} finds a cache!"Write a script-category log line. Supports placeholders (below).
grant <ref> <items>grant self medkit,knifeGive specific items to a tribute (comma or space separated ids).
reward <ref> <items>reward killer medkit,grenadeGive a random item from the list.
ally <ref> <ref>ally self otherForge an alliance between two tributes (Hunger Games+).
leave <ref>leave selfThe tribute leaves their alliance.
trigger <category>trigger fightFire a random regular event of that category (recursion-guarded).
spawn <globalId>spawn the_beastSpawn a global event by its id.
fight <ref> <ref>fight other selfForce a fight event between two tributes (like being caught while stealing).
if <condition> … endif killer is target … endConditional block. Optional else between the branches.

Operators: < > <= >= == != =. Stats use attribute keys like health, energy, food, combat, stealth…

Log placeholders

Inside log "…" strings, wrap any ref to insert its name:

{self} {other} {others} {others[0]} {killer} {victim} {target} {boss}

{others} joins all names ("A, B and C"); {others[N]} picks a specific member by index (out of range → "…"). Works in both mini log strings and event flavour templates.
# example
set target to random
log "A bounty is placed on {target}! Kill them for a reward."

Condition objects

A condition object matches a tribute when all fields pass:

// all fields optional; unknown stat names fail (never crash)
{
  skill: { name: "combat", min: 60, max: 100 },
  stat: { name: "morale", min: 30 },
  proficiency: { name: "melee", min: 50 },
  personality: "warrior",
  gender: "female",
  hasItem: "medkit",
  hasCat: "medical"
}

Example (event script, JS)

// onEvent of a custom event
if (hasCat(self, "medical")) {
  add(self, "morale", 10);
  grant(self, "bandage");
  log("{self} patches themselves up.");
} else {
  add(self, "health", -8);
  log("{self} finds no medicine.");
}

6. Global event hooks

A global event's script is an object with up to five hooks. Each fires at a different point in the global's life.

HookWhenExtra context
onStartWhen the global triggers.state, g, memory
onDay / onNightEach phase while active.state, g, memory
onDeathWhenever a tribute dies while active.death = { tribute, killer } → refs victim, killer
onDamageWhenever a tribute takes health damage while active, and whenever the Boss itself is hit by a hunter.damage = { target, amount, attacker, cause }; refs victim/killer map to target/attacker. If damage.target has maxHealth it's the Boss (use boss()/bossName())
onSlayThe moment a Boss is slain — before the Boss Slayer winners are decided.state, g, memory; g.boss holds participants (everyone who fought it)
onEndWhen the global ends (duration expired, or a boss was slain).state, g, memory
g.memory is the memory object — share state between hooks. It persists while the global is active and resets when it ends.

Example — a modular death blast (JS, onSlay)

// fired the moment the Boss dies, before winners are decided
for (const id of Object.keys(g.boss.participants || {})) {
  const t = byId(id);
  if (t && isAlive(t)) {
    add(t, "health", -60);
    log(t.name + " is caught in the blast!");
  }
}
In Boss Slayer mode the game ends only when all active bosses are dead. Every tribute who fought any slain boss is accumulated in state.bossSlayers; at the final slay the winners are whoever is alive with health > 0 among them — so an onSlay blast here can kill wounded fighters and deny them the win.

Example — react to the active boss (JS)

// boss() returns the active boss entity (or null); bossName() its localized name
const b = boss();
if (b && b.health < b.maxHealth * 0.5) {
  log(bossName() + " is wounded! Its morale falters.");
  b.morale = Math.max(0, b.morale - 10);
}
In mini-language, use the {boss} log placeholder instead: log "The {boss} is wounded!"

Example — onDamage reaction (JS)

// fires when a tribute takes damage AND when the Boss is hit by a hunter
if (damage.target && damage.target.maxHealth) {
  log(bossName() + " was struck for " + damage.amount + " by " + (damage.attacker ? damage.attacker.name : "?") + " — " + damage.remainingCount + " units left");
} else {
  log(damage.target.name + " took " + damage.amount + " damage.");
}
damage.remainingCount (boss hits only) is the squad units still standing: Math.ceil(health × count / maxHealth). The Threat panel shows it live too (e.g. ×2/3) and lists every active boss (up to 4 — the first as a full card, the rest compact, with a "+N more…" footer if exceeded).

Ability hooks (per-tribute)

Abilities can carry a script object with hooks that fire for the tribute's own state. Context is self, state, memory (a per-tribute object, reset each game), and all helpers.

HookWhenExtra context
onEvent / postEventan event involves the tribute (before / after its effects)event = { id, cat, phase }; other = the other participant
onDay / onNighteach phase—
onDamagethe tribute takes damagedamage = { target, amount, attacker, cause }
onDealthe tribute deals damagedamage = { target, amount, cause }
onKillthe tribute kills someonedeath = { tribute, killer }

Example — an ability reacting to events (JS)

// onEvent of the ability's script
if (event.cat === "fight" && other) {
  add(self, "morale", -3);
  log("Battle nerves: " + self.name);
}

The default bounty global (mini-language)

onStart:
set target to random
log "A bounty is placed on {target}! Kill them today for a reward."

onDeath:
if victim is target
  set claimed to true
  if killer is not none
    reward killer medkit,grenade,rations,shield
    log "{killer} claimed the bounty on {victim}!"
  end
  if killer is none
    log "The bounty target has died, but no one collected the reward."
  end
end

onEnd:
if claimed is not true
  log "The bounty on {target} has expired. No reward was paid."
end

7. Outcome text conditions

Events (and sub-events) can have outcome texts — an ordered list of { when, tpl } pairs evaluated after effects are applied. The first matching when wins; an entry with no when is the fallback. If none match, the main template is used.

Conditions use the same mini-language, with self and other:

Example conditionMatches when…
other.dead / self.deadThe other / the actor died from this event.
other.health < 30The other is left badly wounded.
other rel self >= 20The other feels positively about the actor (relationships −100…100).
self.health > 50The actor came through it unharmed.
other female / other warriorGender / personality of the other.
hasItem self medkit / hasCat self medicalInventory checks.

8. Errors & safety

  • Scripts are sandboxed and can never crash the game. A thrown error is written as a script log line and printed to the server console.
  • Unknown attribute / skill / proficiency names are silently ignored — a typo means a no-op, not an error. Watch your spelling.
  • Attribute keys: health energy food morale supplies combat survival craft charm stealth (0–100).
  • Proficiencies: melee ranged explosive tool medical (0–100). Relationships run −100…100.
  • Item ids come from the item catalog (config/items.json or the ⚙ Game Content → Items editor).
  • In the mini-language, self/other are only defined in event scripts — global hooks use random/randomOther or stored memory refs instead.

9. Examples

A "care package" add-on mini-event (JS)

// runs for each alive tribute each phase
if (rand(1, 10) === 1) {
  grantLoot(self, ["water", "rations", "bandage", "firewood"]);
  log("{self} finds a sponsor care package.");
}

A boss that punishes the unprepared (mini, onDay)

onDay:
set target to random
if hasCat target armor
  log "{target} hunkers down as the Beast prowls past."
else
  grant target medkit
  log "{target} is caught in the open by the Beast!"
end

Forcing a truce (mini, onStart)

onStart:
ally random randomOther
log "The Gamemakers decree a truce between two tributes."
